# NGSI-LD Smart Data Models

Notes on the three FIWARE Smart Data Models the broker publishes, and
the small GeoTwin extension on top of them. The model files are not
copied into this repository.

- **Purpose.** A common shape for air quality, weather, and vulnerable
  facilities so Nestos and Sandanski can share entities.
- **State.** Used by Scorpio in the implementation repository.
  WaterLevelObserved is deferred and is not part of the current
  services.
- **Licence.** The notes are documentation (CC BY 4.0). The underlying
  Smart Data Models keep their upstream licence.
- **Location.** <https://github.com/LioncodeYourITPeople/GeoTwin-ELBG/tree/main/docs/smart-data-models>

The attribute list and the extension namespace are summarised in
[data-models/README.md](../data-models/README.md).
