# User manuals

Guides for people using the dashboard: getting started, reading the
map, scenario planning, machine-learning operations, data and privacy,
and AI transparency.

- **Purpose.** Let municipal staff in Nestos and Sandanski use the two
  services without reading the platform docs.
- **State.** Written in English, Greek, and Bulgarian. Served in the
  dashboard at `/help` and stored as Markdown in the implementation
  repository. Recorded in the
  [21 July 2026 asset update](../updates/2026-07-21-user-manuals.md).
- **Licence.** CC BY 4.0, as documentation of this pilot.
