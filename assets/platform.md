# GeoTwin ELBG platform

The implementation of the pilot: ingestion, NGSI-LD broker integration,
both services, the dashboard, and local deployment scripts.

- **Purpose.** Neighbourhood-scale air-quality forecasts and policy
  what-if scenarios for Nestos and Sandanski, using Copernicus and open
  EU data.
- **State.** In active development. Runs locally with Docker Compose.
  Production target is Hetzner Cloud in the EU; not deployed for either
  municipality yet. See [docs/status.md](../docs/status.md).
