# GeoTwin ELBG

Cross-border Local Digital Twin for Nestos (Greece) and Sandanski
(Bulgaria). The pilot uses Copernicus CAMS, Sentinel, and open EU
geospatial data to deliver neighbourhood-scale air-quality forecasts and
policy what-if scenarios, without local IoT sensor hardware.

This repository is the public record of the pilot within
[LDT4SSC](https://ldt4ssc.eu/) (Work Strand 2). It holds structured
updates, a short status note, and pointers to shared outputs. The
implementation lives in
[GeoTwin-ELBG](https://github.com/LioncodeYourITPeople/GeoTwin-ELBG).

The pilot runs from 1 June 2026 to 30 November 2027. Partners are
LIONCODE PC (lead), the Municipality of Nestos, the Municipality of
Sandanski, the Kavala Chamber of Commerce, and LabGeo at the Aristotle
University of Thessaloniki. Metadata for the aggregator is in
[`pilot.yaml`](pilot.yaml).

This repository was created from the
[LDT4SSC pilot template](https://github.com/ldt4ssc/pilot-template)
and follows the LDT4SSC pilot documentation framework.

## Where to look

  assets, and general notes. See [`updates/README.md`](updates/README.md).
- [`docs/status.md`](docs/status.md) — snapshot of what the platform
  contains and what is not live yet.
- [`assets/`](assets/) — pointers to reusable outputs in the
  implementation repository.
- [`data-models/`](data-models/) — NGSI-LD models used by the pilot.
- [`src/README.md`](src/README.md) — link to the implementation
  repository. Source is not copied here.

## What this repository is for

- A single public location for the pilot's work, visible to the LDT4SSC
  community.
- Structured updates that the Knowledge Hub and the LDT4SSC website can
  aggregate.
- A record the pilot owns. If central project infrastructure changes,
  the content here remains intact.
- Outputs that others can cite and reuse.
