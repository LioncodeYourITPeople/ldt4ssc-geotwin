Municipal users can read the dashboard guides in the three languages of
the pilot. Pull request #3 added the Bulgarian set. English and Greek
were already in the tree.

## What the manuals cover

Each language has the same chapters:

- Getting started.
- Reading the map.
- Scenario planning.
- Machine-learning operations.
- Data and privacy.
- AI transparency.

They live in the implementation repository under `docs/user-manuals/`
(`en`, `el`, `bg`) and are also served inside the dashboard at `/help`.
Documentation in this pilot record is CC BY 4.0. The manuals are part
of that documentation set. They are not yet deposited in the LDT4SSC
Assets and Services Repository.
